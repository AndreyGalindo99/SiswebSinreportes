# Sistema de Gestión de Reportes

Plataforma web para la administración, visualización y gestión de reportes e incidencias.

---
## Tecnologías Utilizadas

- **Framework:** React + Vite
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS / CSS Modules
- **Componentes:** Radix UI / Shadcn UI

---

## Instalación y Ejecución

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/AndreyGalindo99/SiswebSinreportes.git
   cd "Sistema de Gestión de Reportes"
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor en modo desarrollo:
   ```bash
   npm run dev
   ```
